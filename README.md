# GenAI Applications

AI applications built using LangChain, Groq, and Streamlit.

## Features
- AI Chatbot
- Research Paper Explainer
- CLI Chat System
- LangChain-based interactions

## Tech Stack
Python, LangChain, Groq API, Streamlit

## Setup
git clone https://github.com/vishwasdto/GenAI-Applications.git
cd GenAI-Applications
pip install -r requirements.txt

Create a .env file and add:
GROQ_API_KEY=your_api_key_here

## Run
streamlit run 4.prompts/1_prompts_ui.py

## Structure
4.prompts/
 ├── 1_prompts_ui.py
 ├── 2_prompt_ui.py
 ├── 3_chatbox.py
 ├── 4_messages.py
